## 남은 과제

- 주소·좌표 (`nsc/geo.py`, 행정안전부 도로명주소 API). 결과는 `state/geocode.json`에 쌓고 새 주소만 묻는다.
  - 검색 API(`JUSO_KEY`, 등록됨) 실측: 장기요양 주소 233 → 354 (도로명코드·건물번호가 일치할 때만 채택), 구 514/514
  - 사회서비스 제공기관 281곳 중 130곳은 사무실이 화성시 밖 (대부분 장애인활동지원 기관) → `office_outside`로 표시, 구는 비움
  - 남은 장기요양 160곳은 도로 이름을 모르는 도로명코드 100개 → 좌표 API가 열리면 법정동 코드 후보로 좌표만 먼저
  - 좌표제공 API(`JUSO_COORD_KEY`): 운영 승인 대기. 승인되면 별도 작업 없이 다음 수집부터 채워짐
  - 브이월드는 해외 IP(GitHub Actions 서버)를 막아 수집에 못 씀 → 지도 화면(국내 브라우저)에서만 사용
- 중앙부처 복지서비스 상세: 4일이면 다 채워짐. 공공데이터포털에서 활용사례를 등록하면 한도 증설 가능
- 교통약자 이동지원센터 표준데이터: 활용신청 필요
- 경기데이터드림 전용 데이터(읍면동별 등록장애인 등): 별도 인증키 필요
