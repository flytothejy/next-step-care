# 아이 발달이 늦다는 말을 들었을 때 — 검증용 한 장

장애아동 가족 시나리오. 진단 전후, 가장 막막한 순간에 무엇부터 할지 안내한다.

- `index.html`: 브라우저로 바로 열거나 A4 한 장으로 인쇄
- `page.html`: Claude 아티팩트로 게시하는 본문
- 내용 기준일: 2026-10-21. 출처는 페이지 하단

흐름: 1 발달 정밀검사(검사비 지원) → 2 발달재활서비스(만 6세 미만은 등록 전에도) → 3 특수교육대상자 선정

## 검증할 때 볼 것

- "장애 등록 없이도 시작할 수 있다"는 점이 부담을 덜어 주는지
- 1→2→3 순서가 실제 경험과 맞나 (병원 진단과 교육청 의뢰 중 무엇이 먼저인지)
- '아이의 마음도 함께 봐 주세요' 상자가 공감되는지, 어색한지
- 빠진 정보: 대기 기간, 치료기관 고르는 법, 화성시 기관 연락처

## 확인이 더 필요한 것

- 화성시 보건소의 영유아 발달지원서비스(지역사회서비스투자사업) 운영 여부
- 화성오산교육지원청 특수교육지원센터 연락처
- 발달재활서비스 2026년 소득 구간별 지원액 (지자체마다 단가 조정)
