# 다음걸음 (next-step-care)

노인·장애 당사자와 보호자에게 **"다음에 뭘 하면 되는지"**를 쉽고 빠르게 알려 주는 공익 서비스 (가칭).
돌봄이 갑자기 필요해졌을 때 받을 수 있는 제도, 우리 동네 기관, 공식 창구를 순서대로 이어 준다.

- 목적: 공익. 수익·경쟁은 고려하지 않음
- 대상: 당사자 / 보호자 두 진입로
- 첫 지역: 화성시 (경기도 데이터 우선)
- 첫 시나리오: 퇴원 후 집에서 돌봐야 할 때
